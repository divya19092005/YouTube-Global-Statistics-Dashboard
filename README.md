# 📊 YouTube Global Trends Analysis Dashboard

## Overview

This project presents an interactive Power BI dashboard designed to analyze global YouTube trends across multiple countries. The dashboard provides insights into video performance, audience engagement, content categories, and regional viewing patterns, enabling data-driven decision-making for content creators, marketers, and analysts.

## Objectives

* Analyze trending YouTube content across different countries.
* Monitor key performance metrics such as views, subscribers, and engagement rates.
* Identify popular content categories and regional trends.
* Provide interactive visualizations for deeper audience insights.

## Tools & Technologies

* **Power BI** – Dashboard development and data visualization
* **Power Query** – Data cleaning and transformation
* **DAX (Data Analysis Expressions)** – Calculated measures and KPIs
* **Data Modeling** – Relationship management and performance optimization

## Key Features

### Data Preparation

* Cleaned and transformed raw YouTube trending datasets using Power Query.
* Handled missing values, duplicate records, and data inconsistencies.
* Created a structured data model for efficient reporting.

### KPI Metrics

Developed KPI cards to monitor:

* Total Views
* Subscriber Count
* Engagement Rate
* Average Likes
* Average Comments
* Trending Video Count

### Interactive Dashboard Components

* Dynamic slicers for country, category, and channel selection.
* Drill-through reports for detailed channel and video analysis.
* Cross-filtering visuals for enhanced user interaction.
* Responsive dashboard design for easy navigation.

### Visualizations

* Trending Videos Analysis
* Category-wise Performance Comparison
* Country-wise View Distribution
* Channel Performance Metrics
* Engagement Trends Over Time
* Regional Content Popularity Analysis

## Business Insights

The dashboard helps users:

* Identify high-performing content categories.
* Understand audience preferences across regions.
* Compare channel performance metrics.
* Track engagement trends and growth opportunities.
* Discover country-specific YouTube content patterns.

## Dashboard Outcomes

* Improved visibility into global YouTube trends.
* Faster identification of top-performing videos and channels.
* Enhanced understanding of regional audience behavior.
* Data-driven content strategy recommendations.
